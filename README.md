# ห้องซ้อม · Music Practice Suite

เว็บแอปฝึกดนตรีฟรี เมนูภาษาไทยธีมมืดสำหรับมือถือ iPad และเดสก์ท็อป พัฒนาครบ 5 เฟสตั้งแต่เครื่องมือพื้นฐานจนถึงสตูดิโอแยกไลน์ดนตรี ตัวเว็บเป็น PWA ที่โฮสต์แบบ static ได้ เสียงและสถิติซ้อมประมวลผลในเบราว์เซอร์ ส่วนโหมด AI เลือกส่งเพลงตรงไปยังคอมของผู้ใช้ที่รัน Local GPU Engine

## เครื่องมือเฟส 1

- **เมโทรนอม** ปรับความเร็ว 30–240 BPM ใช้ Tap Tempo เคาะหลายครั้งเพื่อคำนวณความเร็ว เลือกอัตราจังหวะ 2/4, 3/4, 4/4 หรือ 6/8 และติดตามจังหวะจากไฟกะพริบกับเสียงเน้นต้นห้อง ใน 6/8 ค่า BPM เป็นตัวดำประจุดและมีเสียงเคาะย่อยสามครั้งต่อจังหวะ
- **จูนเนอร์** เปิดไมโครโฟนและเล่นทีละโน้ต จอแสดงชื่อโน้ต ความถี่ และความเพี้ยนเป็น cents โหมดกีตาร์ เบส และอูคูเลเล่เลือกสายเป้าหมายได้ หรือให้เว็บเลือกสายที่ใกล้ที่สุดอัตโนมัติ
- **เวลาซ้อม** เริ่มจับเวลาอัตโนมัติเมื่อเปิดเมโทรนอมหรือจูนเนอร์ หรือกดเริ่มเองได้ สรุปเวลารายวันย้อนหลัง 7 วันตามเขตเวลาในเครื่อง เมื่อออกจากหมวดเครื่องมือพื้นฐาน เมโทรนอมและไมโครโฟนจะหยุด ส่วนเวลาที่เริ่มจับด้วยตนเองจะเดินต่อจนกดพัก สถิติยังอยู่เมื่อโหลดใหม่ในเบราว์เซอร์และโดเมนเดิม
## ฝึกหูและโสตทักษะ เฟส 2

เปิดเมนู **ฝึกหู** แล้วเลือกแบบฝึก ทุกแบบเล่นและประมวลผลเสียงในเบราว์เซอร์ด้วย Web Audio API

- **หน้าที่โน้ตในคีย์** ฟังคอร์ด I–IV–V–I แล้วระบุลำดับของโน้ตเดี่ยวในคีย์ที่สุ่ม เลือกฝึกเฉพาะขั้น 1, 3, 5 ครบ 7 ขั้น หรือครบ 12 เสียงโครมาติก
- **ขั้นคู่เสียงและคอร์ด** เลือกฟังขั้นคู่ทีละโน้ต ขั้นคู่พร้อมกัน หรือฝึกระบุคอร์ด Major, Minor, Diminished, Augmented, Maj7, m7 และ Dom7 สองแบบฝึกแรกเลือกเสียงแกรนด์เปียโนหรือโทนนุ่มได้
- **ฝึกฟัง EQ** ทดลองฟังแต่ละย่านจาก 125 Hz ถึง 8 kHz พร้อมคำอธิบายภาษาไทย แล้วเข้าสู่โหมดทาย 3 ย่านที่ +12 dB, 5 ย่านที่ +9 dB หรือ 7 ย่านที่ +6 dB เปิดลูปแกรนด์เปียโนกับเบส ลูปกลองกับเบสและคอร์ด ลูปกีตาร์ เพลงจากเครื่อง หรือ Pink Noise การสลับ A/B ใช้ลูปเดียวกันโดยไม่เริ่มเพลงใหม่ ไฟล์เพลงที่เลือกเปิดอยู่ในเบราว์เซอร์

แต่ละข้อมีเฉลยพร้อมคำอธิบายและเล่นเสียงซ้ำได้ ตอบถูกได้ 1 คะแนน และตอบอย่างน้อยหนึ่งข้อในวันนั้นเพื่อรักษาสถิติซ้อมต่อเนื่องตามวันที่ในเครื่อง คะแนน ความแม่นยำแยกตามหัวข้อ และวันซ้อมต่อเนื่องแสดงทั้งในหน้าฝึกหูและหน้าหลัก สถิติบันทึกในเบราว์เซอร์เดิม

### ชุดขยายฝึกหูและจังหวะ

ในเมนู **ฝึกหู** เลือกแท็บโน้ตและการเทียบเสียง ทำนองและทางคอร์ด จังหวะ หรือ EQ ด่านของชุดขยายทั้งหมดเปิดให้เล่นฟรี

- **ทางเดินคอร์ด** ฟังโทนิกและลำดับคอร์ดที่สุ่มคีย์จาก 18 แบบ ตั้งแต่ Pop ถึง Jazz/R&B/Soul หลังตอบดูแนวเพลงและกดฟังแต่ละคอร์ดได้
- **ฟังทำนองแล้วเล่นตาม** สุ่มจาก 36 ทำนองในสามระดับ ยาว 3–7 โน้ต มีโน้ตเริ่มต้นบอกไว้ ลิ่มเปียโนสองอ็อกเทฟ ผลถูกผิดทีละโน้ต และปุ่มฟังซ้ำ
- **เคาะจังหวะ** เลือกได้ 20 ด่าน ฟังตัวอย่างหรือนับนำหนึ่งห้องแล้วแตะตามจุด รับผลเร็วหรือช้าเป็นมิลลิวินาที จังหวะภายใน ±40 ms แสดงว่าตรงเป๊ะ ความแม่นยำนับจังหวะภายใน ±85 ms และหักผลจากการเคาะเกิน
- **จับเสียงเพี้ยน** เทียบสองเสียงจากตัวอย่างเปียโนเดียวกัน โดยเสียงที่สองอาจเท่าเดิมหรือเปลี่ยนระดับ ±5–50 cents

สถิติฝึกหูเก็บความแม่นยำทุกครั้งและดาวสูงสุดที่เคยได้ของแต่ละด่านในเบราว์เซอร์ คะแนน 45%, 70% และ 90% ขึ้นไปได้ 1, 2 และ 3 ดาวตามลำดับ

## สตูดิโอฝึกร้องเพลง เฟส 3 และชุดขยายที่ 2

- **ทดสอบช่วงเสียง** ร้องโน้ตต่ำสุดและสูงสุดที่ร้องสบายในคนละขั้นตอน ประคองแต่ละโน้ต 1.5 วินาทีแล้วกดบันทึก เทียบช่วงที่วัดได้กับกลุ่มเสียงอ้างอิง 6 กลุ่ม และใช้ช่วงนี้เลือกคีย์เริ่มต้นให้แต่ละแบบฝึก
- **ฝึกลมหายใจ** มีผ่อนคลาย 4–4–6, คุมลมนิ่ง 4–2–10, Farinelli 5–5–15, Catch Breath และ Staccato ฮ่า–ฮ่า–ฮ่า ดูวงกลมและตัวนับเวลาพร้อมเสียงเคาะที่ปิดได้ ฝึกครบสามรอบจะบันทึกเวลา ใช้งานได้โดยไม่ขอไมโครโฟน
- **วอร์มเสียง** มี 18 แบบ แบ่งเป็นเปิดคอและวอร์มพื้นฐาน เชื่อมช่วงเสียง Riffs & Runs และความแม่นยำกับเสียงยาว แต่ละแบบแนะนำพยางค์และวิธีร้องภาษาไทย ปรับได้ 40–180 BPM และเลื่อนคีย์ทีละครึ่งเสียง ฟังเปียโนและเสียงนับเข้า แล้วร้องตามกราฟ Canvas
- **ร้องทำนอง** มี 12 บท ความยาว 4–8 ห้อง เลือก Pop Ballad, Soul/R&B, Acoustic Folk หรือเพลงดั้งเดิม ได้แก่ Amazing Grace, Greensleeves, Scarborough Fair และ Ode to Joy เปียโนเล่นคอร์ดคลอและปิดเมโลดี้ไกด์ได้ ใช้หูฟังเพื่อให้ไมโครโฟนจับเสียงร้องได้ชัด
- **เกมร้องเก็บดาว** เลือกสเกลกับคีย์ ฟังเสียงเปียโนตัวอย่าง แล้วร้องโน้ตให้ยานขึ้นลงเพื่อรับดาว จับโน้ตได้ติดต่อกันจะเพิ่มคอมโบ
- **คะแนนและประวัติ** การวอร์มเสียงและร้องทำนองนับช่วงที่ร้องตรงภายใน ±50 cents เว้นช่องพักและเวลาผ่อนผันสั้น ๆ ตอนเปลี่ยนโน้ต คะแนนเกมคำนวณจากสัดส่วนดาวที่เก็บได้ ให้ดาวประจำด่านที่ 45%, 70% และ 90% หน้าหลักรวมดาวสูงสุดของแต่ละด่านพร้อมประวัติและเวลาซ้อม ทุกแบบฝึกเปิดให้เล่นฟรี

เปิดเว็บผ่าน HTTPS บน Safari iPad แล้วแตะเปิดไมโครโฟนหรือเริ่มรอบซ้อม หาก Safari พักระบบเสียงระหว่างขอสิทธิ์ ให้แตะปุ่มเริ่มเสียงที่แสดงหลังอนุญาต หากเคยปฏิเสธสิทธิ์ ให้เปิดสิทธิ์ในเมนูการตั้งค่าเว็บไซต์ของ Safari แล้วแตะเริ่มอีกครั้ง แอปหยุดใช้ไมโครโฟนเมื่อเปลี่ยนเครื่องมือ ออกจากหน้า หรือสลับแอป และบันทึกช่วงโน้ต คะแนน คอมโบ และเวลาในเบราว์เซอร์

## ห้องซ้อมเครื่องดนตรีและแกะเพลง เฟส 4 และชุดขยายที่ 3

- **เปียโนและโน้ตไหล** มี 32 บท แบ่งเป็นพื้นฐาน ไล่นิ้วสไตล์ Hanon สเกลและอาร์เพจจิโอ ฝึกสองมือ หมวดละ 6 บท และเพลงบรรเลงกับคลาสสิก 8 บท ได้แก่ Ode to Joy, Für Elise, Canon in D, Minuet in G, Moonlight Sonata, Korobeiniki, Jazz Boogie และ Pop Ballad Theme ในบทที่ระบุมือ เลือกซ้อมมือซ้าย มือขวา หรือสองมือได้
- **การเล่นเปียโน** Wait Mode รอให้เล่นครบทุกโน้ตในจังหวะนั้น ใช้ลิ่มเปียโนบนจอแบบหลายสัมผัส ไมโครโฟนสำหรับโน้ตเดี่ยว หรือคีย์บอร์ด Web MIDI ในเบราว์เซอร์ที่รองรับ เสียง Salamander Grand Piano ตอบสนองน้ำหนักกด นำเข้า MIDI ฟอร์แมต 0 หรือ 1 ที่ใช้ PPQ ได้
- **ตีคอร์ดตามจังหวะ** มี 16 แพตเทิร์นใน 8 แนว เลือกเสียงจำลองกีตาร์หรืออูคูเลเล่ ปรับ 30–240 BPM และเปลี่ยนคอร์ดแต่ละห้องในลูป 4 ห้องได้ ลูกศรและเครื่องหมายอุดสายไฮไลต์ตามเมโทรนอม กดหยุดเพื่อบันทึกเวลาที่ซ้อมหลังจังหวะนับนำ
- **จำโน้ตบนคอ** เลือกกีตาร์โปร่ง/ไฟฟ้า เบส หรืออูคูเลเล่ สำรวจโน้ตและสเกลตั้งแต่สายเปิดถึงเฟร็ต 12 แล้วเล่นโจทย์ 60 วินาทีแบบแตะหาโน้ตบนสายที่กำหนดหรือทายชื่อโน้ตจากตำแหน่งที่ไฮไลต์ แตะเพื่อฟังเสียงตามระดับเสียงของโน้ต
- **อ่านโน้ต** เลือกกุญแจซอล กุญแจฟา หรือบรรทัดคู่ มีโน้ตในบรรทัด เส้นน้อย และชาร์ป/แฟลต ตอบด้วยชื่อโน้ตสากลหรือโด–เร–มี เล่นลิ่มเปียโนบนจอ หรือใช้ Web MIDI เลือกฝึกอิสระหรือจับเวลา 60 วินาที
- **คลังคอร์ด** มีผังนิ้วกีตาร์และอูคูเลเล่อย่างละ 10 คอร์ด พร้อมตัวอย่างเสียงดีด โหมดซ้อมสุ่มคอร์ดปรับ BPM และเลือก 2, 4 หรือ 8 จังหวะต่อคอร์ดได้ กด **ทำทัน** เพื่อประเมินการเปลี่ยนคอร์ดด้วยตนเอง
- **แกะเพลง** เปิด MP3, WAV, M4A หรือไฟล์เสียงที่เบราว์เซอร์ถอดรหัสได้ แตะคลื่นเสียงหรือใช้แถบเลื่อนเพื่อเลือกท่อน ปรับความเร็ว 0.5–1.5× โดยรักษาคีย์ และตั้ง A–B ให้วนซ้ำ เลือกฟิลเตอร์เน้นเบส เน้นย่านกลาง หรือกดสัญญาณกลางของไฟล์สเตอริโอเพื่อลดเสียงร้อง ไฟล์ที่เบราว์เซอร์เล่นได้แต่ถอดเป็นคลื่นเสียงไม่ได้ยังเลือกท่อนได้ด้วยแถบเลื่อน

ทุกด่านเปิดฟรี หน้าหลักแสดงความแม่นยำ ดาวสูงสุดของแต่ละด่าน และเวลาซ้อม ประวัติและไฟล์ MIDI หรือเสียงอยู่ในเครื่องผู้ใช้ คะแนนเปียโนคิดจากโน้ตที่เล่นถูกเทียบกับจำนวนโน้ตทั้งหมดบวกจำนวนกดผิด เกมโน้ตใช้ความแม่นยำให้ดาวที่ 45%, 70% และ 90% โหมดจับเวลาคิดดาวจากอย่างน้อย 5 โจทย์เพื่อให้ดาวสะท้อนทั้งความเร็วและความแม่นยำ

ใช้ Web MIDI ผ่าน HTTPS ในเบราว์เซอร์ที่รองรับ หาก Safari บน iPad ไม่มี Web MIDI ให้ใช้ลิ่มเปียโนบนจอสำหรับโน้ตไหลและอ่านโน้ต กุญแจและเครื่องหมายบรรทัดห้าเส้นใช้เส้นเวกเตอร์จาก Noto Music (SIL OFL 1.1)

## สตูดิโอแยกไลน์ดนตรี เฟส 5

เปิดเมนู **แยกไลน์ดนตรี** มิกเซอร์มี 4 แทร็ก ได้แก่ ร้อง กลอง เบส และดนตรีอื่น ๆ ปรับระดับเสียงแต่ละแทร็ก ปิดเสียงด้วย Mute หรือเลือกฟังด้วย Solo ได้ ตัวเล่นใช้ AudioContext เดียวกันเพื่อให้ทุกแทร็กเริ่มพร้อมกันและวน A–B ที่ตำแหน่งเดียวกัน ปรับความเร็วได้ 0.5–1.5× การเปลี่ยนความเร็วในมิกเซอร์เปลี่ยนระดับเสียงโน้ตตามอัตราเล่น ถ้าต้องการชะลอไฟล์เดียวโดยรักษาคีย์ ให้ใช้เครื่องมือแกะเพลงเฟส 4

| โหมด | วิธีใช้ |
|---|---|
| แยกย่านทันที | เปิดเพลงหนึ่งไฟล์ เบราว์เซอร์แยกย่านโดยประมาณด้วย Mid/Side และตัวกรองหลายย่าน เสียงที่อยู่ตำแหน่งหรือย่านเดียวกันอาจติดมาด้วย |
| แยกด้วย AI บนคอม | กรอกที่อยู่ Engine กับรหัสเชื่อมต่อ แล้วเลือกเพลง Demucs จะแยกเป็น WAV สี่แทร็กและส่งกลับเข้ามิกเซอร์ |
| นำเข้าแทร็กแยก | เลือกไฟล์ให้ตรงช่องร้อง กลอง เบส หรือดนตรีอื่น ๆ เลือกบางช่องได้ ใช้ไฟล์ที่เริ่มจากจุดเดียวกันเพื่อให้ตรงจังหวะ |

### รัน Local GPU Engine และใช้จาก iPad

1. ดาวน์โหลดและแตกไฟล์ทั้งโปรเจกต์ ติดตั้ง Python 3.10–3.12, FFmpeg และ Node.js พร้อม npm หากต้องการเปิดเว็บผ่าน LAN
2. เปิด `local-gpu-engine/start_windows.bat` บน Windows หรือรัน `./start_mac_linux.sh` ในโฟลเดอร์นั้นบน macOS/Linux สคริปต์สร้าง virtual environment ติดตั้งไลบรารี และ build เว็บให้เมื่อมี npm และยังไม่มีไฟล์ build
3. ต่อ iPad และคอมเข้าวง Wi‑Fi เดียวกัน เปิด **Wi-Fi / iPad URL** ที่หน้าต่าง Engine แสดง เช่น `http://192.168.1.25:8765` แล้วกรอกที่อยู่นั้นและ **Connection code** ในแท็บแยกด้วย AI
4. กดตรวจการเชื่อมต่อแล้วเลือกเพลง เครื่องจะใช้ CUDA, MPS หรือ CPU ตามฮาร์ดแวร์และ PyTorch ครั้งแรกต้องต่ออินเทอร์เน็ตเพื่อดาวน์โหลดโมเดล หลังดาวน์โหลดแล้วงานแยกเสียงรันในเครื่อง

หากเปิดเว็บผ่าน Vercel ให้ใช้ที่อยู่ Engine แบบ HTTPS ที่ iPad เชื่อถือ และตั้ง `STEM_ALLOWED_ORIGINS` ให้ตรงกับ origin ของเว็บ หน้า LAN ที่ Engine เปิดให้เป็นทางเลือกสำหรับ Safari ที่บล็อก HTTPS เรียก HTTP ดูวิธีติดตั้ง FFmpeg ตั้งค่าใบรับรอง และใช้ API ที่ [คู่มือ Local GPU Engine](local-gpu-engine/README.md)

## เสียงแกรนด์เปียโน

ฝึกหู เสียงนำในวอร์มเสียง และเปียโนโน้ตไหลใช้ไฟล์ MP3 บันทึกจริงจากชุด Salamander Grand Piano ของ Alexander Holm โดยเลือกตัวอย่างทุก 3 ครึ่งเสียงตั้งแต่ A0 ถึง C8 เปลี่ยนอัตราเล่นเพื่อสร้างโน้ตการคั่น ปรับน้ำหนักเสียงและหางเสียง และเติมเสียงสะท้อนห้องสั้น ๆ เว็บโฮสต์ไฟล์ย่อยจาก Tone.js เอง โหลดโน้ตที่ใช้ตามต้องการ และเก็บตัวอย่างที่โหลดแล้วไว้ในแคช PWA หากตัวอย่างยังโหลดอยู่หรือโหลดไม่ได้ จะเล่นเสียงสังเคราะห์สำรองพร้อมแสดงสถานะ ชุดย่อยและการปรับเสียงระหว่างเล่นอิงจากต้นฉบับ [Salamander Grand Piano ของ Alexander Holm](https://github.com/Tonejs/audio/tree/master/salamander) · [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)

## รันบนเครื่อง

ต้องใช้ Node.js 22.12 ขึ้นไปหรือ Node.js 20.19 ขึ้นไปในสาย 20 พร้อม npm

```bash
git clone https://github.com/bosszest964-star/Music-training-.git
cd Music-training-/web
npm ci
npm run dev
```

เปิด URL localhost ที่ Vite แสดง ปุ่มเปิดไมโครโฟนใช้ได้ผ่าน HTTPS หรือ localhost หากทดสอบจากมือถือหรือ iPad ให้เปิด URL HTTPS จาก Vercel เพื่อให้เบราว์เซอร์ขอสิทธิ์ไมโครโฟนได้ เมโทรนอมและจูนเนอร์ออกแบบสำหรับใช้ขณะเปิดหน้าแอป เพราะระบบปฏิบัติการอาจพักเสียงและจำกัดตัวตั้งเวลาเมื่อสลับแอปหรือล็อกหน้าจอ

## ตรวจโค้ดและทดสอบ production build

รันจาก `web/`

```bash
npm run lint
npm run check
npm run build
npm run preview
```

เปิด URL จาก `npm run preview` เพื่อทดสอบ Service Worker หลังการโหลดครั้งแรกและติดตั้งแคชเสร็จแล้ว ให้ปิดการเชื่อมต่อและรีโหลดเพื่อทดสอบออฟไลน์ บน iPad หรือ iPhone เปิดด้วย Safari แล้วเลือก **แชร์ → เพิ่มไปยังหน้าจอโฮม** บนเบราว์เซอร์เดสก์ท็อปที่รองรับ ให้ใช้คำสั่ง **ติดตั้งแอป** ของเบราว์เซอร์

## นำขึ้น Vercel ฟรี

1. ส่งโค้ดไปยัง repository ของคุณบน GitHub แล้วลงชื่อเข้า [Vercel](https://vercel.com/) ด้วยแผน Hobby สำหรับโปรเจกต์ส่วนตัวภายในโควตาของแผน
2. เลือก **Add New → Project** แล้วนำเข้า repository
3. ตั้ง **Root Directory** เป็น `web` และ **Framework Preset** เป็น **Vite**
4. ใช้ **Install Command** เป็น `npm ci`, **Build Command** เป็น `npm run build` และ **Output Directory** เป็น `dist` ไม่ต้องเพิ่มตัวแปรสภาพแวดล้อม
5. กด **Deploy** แล้วเปิด URL `*.vercel.app` ที่ระบบให้มาเพื่อทดสอบเมโทรนอมและอนุญาตใช้ไมโครโฟน

โค้ดเว็บอยู่ใน `web/` และผล build อยู่ใน `web/dist/` ส่วน FastAPI, Demucs และสคริปต์ติดตั้งอยู่ใน [local-gpu-engine/](local-gpu-engine/)
