# Local GPU Engine

โฟลเดอร์นี้เตรียมไว้สำหรับเฟส 5 เพื่อแยกแทร็กเสียงร้องและเครื่องดนตรีด้วยโมเดลที่รันบนการ์ดจอของผู้ใช้เอง แล้วเปิดไฟล์เสียงที่ได้กลับมาในเว็บเพื่อฝึกซ้อมหรือแกะเพลง

ในเฟส 5 จะเลือกโมเดลที่ตรวจสอบเงื่อนไขสิทธิ์ได้ ระบุระบบปฏิบัติการและ GPU ที่รองรับ และทดสอบการใช้หน่วยความจำด้วยไฟล์เสียงหลายความยาว เริ่มจากการแลกเปลี่ยนไฟล์ผ่านเครื่องผู้ใช้ก่อนพิจารณาวิธีเชื่อมกับเว็บโดยตรง

เฟส 1 ใช้งานทั้งหมดได้จาก `web/` โดยไม่ต้องติดตั้งโมเดลหรือเครื่องมือนี้
